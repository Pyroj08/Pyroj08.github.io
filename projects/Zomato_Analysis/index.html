Zomato Restaurant Analysis

This project performs a comprehensive analysis of the Zomato dataset for Bangalore to uncover insights into restaurant trends, ratings, costs, and cuisine popularity. The workflow involved designing a relational database, executing an ETL pipeline with Python for data cleaning, performing in-depth SQL analysis, and visualizing the findings in an interactive Power BI dashboard.

Project Process

1. Database Design & Schema

A normalized relational database schema was created in MySQL to structure the data, eliminate redundancy, and ensure data integrity. The schema consists of three tables: restaurants, cuisines, and the linking table restaurant_cuisines to manage the many-to-many relationship.


-- SQL Schema from Schema_and_Table_creation.sql
CREATE TABLE restaurants (
    restaurant_id INT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(255) NOT NULL,
    restaurant_type VARCHAR(255),
    has_online_order BOOLEAN,
    has_table_booking BOOLEAN,
    rating DECIMAL(3, 2), 
    votes INT,
    cost_for_two INT
);

CREATE TABLE cuisines (
    cuisine_id INT PRIMARY KEY AUTO_INCREMENT,
    cuisine_name VARCHAR(100) UNIQUE NOT NULL
);

CREATE TABLE restaurant_cuisines (
    rc_id INT PRIMARY KEY AUTO_INCREMENT,
    restaurant_id INT,
    cuisine_id INT,
    FOREIGN KEY (restaurant_id) REFERENCES restaurants(restaurant_id),
    FOREIGN KEY (cuisine_id) REFERENCES cuisines(cuisine_id)
);

2. Data Cleaning & ETL

A Python script, detailed in the Data_Cleaning_and_Storage.ipynb notebook, was used to perform the ETL process. Key transformation steps included dropping irrelevant columns, renaming columns for clarity, handling null values, removing duplicates, converting data types (e.g., `rate` to numeric, `cost_for_two` to integer), and mapping categorical columns like `online_order` to boolean values. The cleaned data was then loaded into the MySQL database using SQLAlchemy.

SQL Analysis & Insights

Top 10 Restaurant Chains

Question: Which restaurant chains have the most outlets in Bangalore?

Insight: This query identifies the most dominant chains by outlet count, a key indicator of market share and brand presence. The dashboard shows that chains like North Indian and Chinese are leaders.
-- From Top_10_Restaurant_Chains.sql
SELECT name AS restaurant_chain, COUNT(*) AS number_of_outlets
FROM restaurants
GROUP BY name
ORDER BY number_of_outlets DESC
LIMIT 10;

Impact of Online Ordering

Question: How does offering online ordering affect a restaurant's average rating and vote count?

Insight: The analysis shows that the vast majority of restaurants (64.48%) have online ordering capabilities, indicating its importance in the market.
-- From Impact_of_Online_Ordering.sql
SELECT
    CASE WHEN has_online_order = 1 THEN 'Yes' ELSE 'No' END AS has_online_order,
    COUNT(*) AS number_of_restaurants,
    ROUND(AVG(rating), 2) AS average_rating,
    ROUND(AVG(votes), 0) AS average_votes
FROM restaurants
WHERE rating IS NOT NULL
GROUP BY has_online_order;

Average Cost for Top Cuisines

Question: What is the average cost for two at restaurants serving the top 5 most popular cuisines?

Insight: By calculating the average cost for the most widespread cuisines, we can gauge the general price point and affordability of the most popular dining options in the city. The dashboard shows that North Indian and Chinese are among the most popular cuisines.
-- From Average_Cost_for_Top_Cuisines.sql
WITH TopCuisines AS (
    SELECT c.cuisine_id
    FROM cuisines c
    JOIN restaurant_cuisines rc ON c.cuisine_id = rc.cuisine_id
    GROUP BY c.cuisine_id
    ORDER BY COUNT(rc.restaurant_id) DESC
    LIMIT 5
)
SELECT
    tc.cuisine_name,
    ROUND(AVG(r.cost_for_two), 2) AS average_cost_for_two
FROM restaurants r
JOIN restaurant_cuisines rc ON r.restaurant_id = rc.restaurant_id
JOIN TopCuisines tc ON rc.cuisine_id = tc.cuisine_id
WHERE r.cost_for_two IS NOT NULL
GROUP BY tc.cuisine_name
ORDER BY average_cost_for_two DESC;
