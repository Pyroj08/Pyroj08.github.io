Zomato Restaurant Analysis

This project demonstrates a complete analytics workflow to uncover key business drivers from raw restaurant data, moving from database design and ETL to a final, interactive Power BI dashboard that highlights market trends and restaurant performance.

Power BI Dashboard

The insights from the SQL analysis were visualized in an interactive, two-page dashboard. The first page provides a high-level executive summary of the Bangalore restaurant market, while the second offers a deep dive into relationships between variables like cost, rating, and restaurant type.

Process & Schema

The project began with designing a normalized relational database in MySQL to properly structure the data. A Python script was then used for the ETL process: extracting the raw CSV, cleaning and transforming the data with Pandas, and loading it into the database using SQLAlchemy.
