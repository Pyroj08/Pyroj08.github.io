Project Overview

This project demonstrates the complete workflow for analyzing e-commerce sales data:

  • Imported raw CSV files into MySQL database.
  • Cleaned & transformed data in Python (using Pandas & SQLAlchemy).
  • Stored cleaned dataset back into MySQL for structured access.
  • Built an interactive Power BI dashboard to generate insights.

Database Schema

The schema illustrates the relational structure of the e-commerce dataset, detailing tables for orders, products, customers, and payments to ensure data integrity and efficient querying.

Power BI Dashboard

A preview of the interactive dashboard pages, which highlight KPIs, sales trends over time, customer segmentation, and product performance.

Key Insights

Sales Peaks

Sales show a significant peak in the second quarter (Q2), suggesting opportunities for mid-year marketing campaigns.

Loyal Customers

The top 10% of customers contribute to nearly half (47.17%) of total revenue, highlighting the importance of loyalty programs.

Payment Methods

Credit card payments are the most frequent transaction method, used in almost three-quarters of all purchases.

Delivery Delays

Analysis shows that delivery delays are most commonly linked to specific geographic regions, pointing to logistical bottlenecks.

Tech Stack

  • SQL (MySQL): Utilized for database design, relational schema implementation, data storage, and complex querying.
  • Python: The core tool for data cleaning, transformation, handling missing values, and performing exploratory data analysis (EDA).
  • Key Libraries (Pandas, SQLAlchemy): Pandas for data manipulation and analysis; SQLAlchemy for seamless integration between Python and the MySQL database.
  • Power BI: Employed for creating a dynamic and interactive multi-page dashboard to visualize findings and generate business insights.
