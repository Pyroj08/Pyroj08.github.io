E-Commerce Data Analysis Project

Problem: An e-commerce company's raw sales data was siloed and difficult to analyze, preventing strategic decision-making. Action: I engineered a complete data pipeline by designing a MySQL database, performing ETL with Python to clean and structure the data, and building an interactive Power BI dashboard. Result: The solution unlocked critical insights, such as identifying that the top 10% of customers generate 47% of revenue, enabling the business to focus on high-value customer retention.

SQL Analysis

The insights in the dashboard were driven by SQL queries. Below are examples of the logic used to uncover key findings.

Top Customers by Revenue

This query uses a Common Table Expression (CTE) and a window function (NTILE) to segment customers into deciles based on total spending, identifying the high-value group.

WITH CustomerRevenue AS (
    SELECT c.customer_id, SUM(p.payment_value) AS total_revenue
    FROM customers c
    JOIN orders o ON c.customer_id = o.customer_id
    JOIN payments p ON o.order_id = p.order_id
    GROUP BY c.customer_id
)
SELECT
    COUNT(*) AS top_10_percent_customers,
    SUM(total_revenue) / (SELECT SUM(total_revenue) FROM CustomerRevenue) * 100 AS revenue_percentage
FROM (
    SELECT *, NTILE(10) OVER (ORDER BY total_revenue DESC) as percentile
    FROM CustomerRevenue
) AS PercentiledCustomers
WHERE percentile = 1;

Sales by Quarter

This query extracts the quarter from the purchase timestamp to aggregate sales value, identifying seasonal trends and peak performance periods.

SELECT
    CONCAT('Q', QUARTER(o.order_purchase_timestamp)) AS sales_quarter,
    SUM(p.payment_value) AS quarterly_sales
FROM orders o
JOIN payments p ON o.order_id = p.order_id
WHERE o.order_status = 'delivered'
GROUP BY sales_quarter
ORDER BY quarterly_sales DESC;
