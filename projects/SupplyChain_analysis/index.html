Supply Chain Analytics Project

An in-depth analysis of a global supply chain dataset, using Python for data processing and Tableau for creating interactive visualizations.

Project Overview

This project analyzes a real-world supply chain dataset to identify key trends and inefficiencies. The workflow includes:

  • Data loading and initial exploration in Python using Pandas.
  • In-depth data cleaning to handle inconsistencies and missing values.
  • Exploratory Data Analysis (EDA) to uncover patterns related to shipping, product types, and customer segments.
  • Development of a comprehensive, multi-page Tableau dashboard for interactive data visualization.

Tableau Dashboard

The interactive dashboard provides multiple views into the supply chain data, focusing on delivery status, sales performance, and profitability across different product categories and regions.

Key Insights

  • Late delivery risk is highest for orders using 'Standard Class' shipping, indicating a need for logistical review.
  • 'Fan Shop' and 'Sporting Goods' are the most profitable product categories, suggesting they are key drivers of revenue.
  • Customer segmentation reveals that the 'Consumer' segment generates the highest sales, but the 'Corporate' segment has higher average profitability per order.
  • Geographic analysis shows significant sales concentration in North America, with emerging markets showing high growth potential.

Tech Stack

  • Python: Used for all data wrangling, cleaning, and exploratory analysis tasks.
  • Key Libraries (Pandas, Matplotlib, Seaborn): Pandas for efficient data manipulation; Matplotlib and Seaborn for generating initial static plots and understanding data distributions.
  • Tableau: The primary tool for building the final, interactive dashboards and performing deep-dive visual analysis.
  • Jupyter Notebook: The environment used for coding, documenting the analysis process, and presenting findings.
