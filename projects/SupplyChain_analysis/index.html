Supply Chain Analytics Project

This project analyzes Supply Chain Operations using the DataCo Supply Chain dataset. The goal was to explore delivery performance, profitability, and sales distribution to optimize decision-making. The workflow included:

  • Data Cleaning & Preparation in Python (Jupyter Notebook)
  • Exploratory Data Analysis (EDA) of delays, sales patterns, and profitability
  • Interactive dashboards built with Tableau
  • Insights on customer segments, shipping modes, and delivery status
