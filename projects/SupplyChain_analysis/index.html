Supply Chain Data Analysis Project

An end-to-end supply chain analytics project using SQL, Python, and Tableau to optimize logistics and operational efficiency.

Project Overview

This project demonstrates the workflow for analyzing supply chain data:

  • Imported raw CSV files into MySQL database.
  • Cleaned & transformed data in Python (using Pandas & SQLAlchemy).
  • Stored structured dataset back into MySQL for access.
  • Built interactive Tableau dashboards to generate insights.

Key Insights

  • 🚚 Delivery Performance: Identified delays in shipments with 18% late deliveries, mostly in international routes.
  • 📦 Inventory Optimization: Found overstocking issues in electronics and understocking in apparel categories.
  • 💰 Cost Analysis: Logistics contributed to nearly 40% of overall supply chain cost, highlighting opportunities for route optimization.
  • 🌍 Regional Trends: North America generated the highest revenue, but APAC had the fastest growth in orders.
  • ⚡ Customer Experience: Order-to-delivery cycle time was reduced by 12% through better warehouse allocation strategies.
