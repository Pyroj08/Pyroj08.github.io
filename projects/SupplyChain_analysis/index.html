Project Overview

This project analyzes a real-world supply chain dataset to identify key trends and inefficiencies. The workflow includes data loading, in-depth cleaning and EDA using Python to uncover patterns, and the development of a Tableau dashboard for visualization.

Tableau Dashboard

The interactive dashboard provides multiple views into the supply chain data, focusing on delivery status, sales performance, and profitability across different product categories and regions.

Challenges & Solutions

  • Challenge: The dataset contained over 180,000 records with inconsistent data types and missing values.
    Solution: I implemented a data cleaning pipeline in Python to standardize data formats, handle null values, and create new features like 'shipping_variance' for deeper analysis.
  • Challenge: Identifying the root cause of delivery delays required analyzing multiple variables simultaneously.
    Solution: I used Tableau to create an interactive dashboard with cross-filtering, allowing stakeholders to dynamically explore the relationship between shipping mode, region, and delivery status.

Key Insights

Shipping Inefficiencies

Late delivery risk is highest for 'First Class' shipping, indicating a need for logistical review or SLA adjustments.

Top Profit Drivers

The 'Fishing' category is the most profitable, suggesting it is a key driver of overall business revenue.

Customer Segments

The 'Consumer' segment drives the highest sales volume, but the 'Corporate' segment has higher average profitability per order.

Geographic Performance

Sales are heavily concentrated in the USA, with emerging markets in South America showing high growth potential.

Tech Stack

  • Python: Used for all data wrangling, cleaning, and exploratory analysis tasks.
  • Key Libraries (Pandas, Matplotlib, Seaborn): Pandas for efficient data manipulation; Matplotlib and Seaborn for generating initial static plots and understanding data distributions.
  • Tableau: The primary tool for building the final, interactive dashboards and performing deep-dive visual analysis.
  • Jupyter Notebook: The environment used for coding, documenting the analysis process, and presenting findings.
